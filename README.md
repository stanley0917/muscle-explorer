# 训练肌肉图谱

从训练动作查找肌肉，也从肌肉查找可选动作。图谱包含 35 个动作、25 个肌群，区分主要训练与辅助参与，并提供深层肌群的局部剖示。设计人：Stanley。

## 打开与使用

直接双击根目录的 `index.html`，无需服务器、安装依赖或联网。请保留目录结构，HTML 会从相邻目录加载脚本、样式和图片。建议使用 PC 端，以 1920 × 1080 分辨率查看；窄窗口保持横向三栏，可以横向滚动。

- 悬停动作或肌肉可预览；点击可固定，按 Esc 取消。
- 搜索支持动作名称、肌肉名称及主训／办公用途。
- “显示辅助与稳定”开关控制辅助肌群及反查结果。
- 标签区分主训练、办公室运动和共用动作；高亮颜色表示训练关系，不代表激活强度。

## 生成分享包

使用 Node.js 18 或更高版本，在项目目录运行：

```sh
node scripts/build-share.cjs
```

生成 `dist/训练肌肉图谱.html` 和 `dist/训练肌肉图谱.zip`。ZIP 内含单文件网页和“办公室碎片化运动方案.png”。单文件网页内嵌全部资源，解压后可离线打开，并可再次点击“获取源码”打包分享。

规范版首页的“获取源码”下载预生成 ZIP。修改源码后请重新执行构建命令；从 Git 获取项目后也需先构建，才能使用此下载入口。普通浏览不需要 Node.js。

## 项目结构

| 目录或文件 | 用途 |
| --- | --- |
| `index.html` | 页面结构与本地资源入口 |
| `css/` | 页面样式 |
| `js/` | 数据、肌群映射、解剖几何、ZIP 打包与页面交互 |
| `assets/images/` | 两张无损 WebP 解剖底图与办公室方案 PNG |
| `scripts/` | 无第三方依赖的分享版构建脚本 |
| `tests/` | 内容基准、模型与构建回归测试 |
| `docs/` | 维护说明 |
| `dist/` | 可重新生成的分享产物，不纳入 Git |
| `local/` | 旧版本、参考资料和本轮验证记录，仅保存在本机 |

## 验证

```sh
node --test tests/*.test.cjs
```

测试使用 Node.js 内置测试工具。浏览器检查脚本与运行方式见 [维护说明](docs/maintenance.md)。
